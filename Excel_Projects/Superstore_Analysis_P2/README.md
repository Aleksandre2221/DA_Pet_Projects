## Description
This project explores Superstore’s sales performance using **Excel**, leveraging **Power Query**, **Power Pivot**, DAX, and interactive **Pivot Table–based dashboards**.
The analysis focuses on revenue trends, customer purchasing behavior, product and category profitability, regional performance, and discount impact on margins.


The dashboard delivers key insights, including:
- Overall revenue and profitability performance  
- Sales breakdown by category, subcategory, state, city, and region  
- Effect of discounts on sales results  
- Detailed product-level performance  
- In-depth analysis by geographic location

## Key Features
- Automated data loading & cleaning using **Power Query**
- Star-schema data model built in **Power Pivot**
- Custom KPIs calculated and metrics created using **DAX**
- Filtering by category, subcategory and date 
- Revenue, margin, discount, and other insights
- Fully interactive, multi-page Excel dashboard for exploratory analysis
